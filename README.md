# Pequenos Registros

Álbum digital para pais registrarem e preservarem momentos importantes da infância de seus filhos.

Consulte [AGENTS.md](AGENTS.md) e a pasta [docs/](docs/) para especificação de produto, arquitetura, banco de dados, design system e roadmap.

## Scripts

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run lint` — executa o ESLint
- `npm run preview` — pré-visualiza o build de produção
